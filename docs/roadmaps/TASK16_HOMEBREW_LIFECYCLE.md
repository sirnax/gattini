## Formula failures and fixes

The first actual `brew install --ignore-dependencies --build-from-source local/gattini/gattini` failed with `ArgumentError: wrong number of arguments (given 3, expected 2)`. The formula had passed Ruby syntax but incorrectly called `chmod` with three arguments. The renderer now passes the two command paths as one array. The corrected `0.1.0` fixture installed successfully.

The first `brew test local/gattini/gattini` failed with `ArgumentError: wrong exec redirect action` at `Kernel#spawn`: its `Pathname` log targets needed strings. After converting both with `.to_s`, the old formula's fake-job test passed. `brew audit --strict --formula local/gattini/gattini` then reported seven style issues in the `0.2.0` formula. The renderer was corrected: Homebrew infers the version from the archive URL, dependencies have the required order, the wrapper uses `formula_opt_bin`, and the test uses audit-compatible assertions and formatting. The final **strict audit exited 0 with no findings**, and the corrected final formula passed `ruby -c` (`Syntax OK`) and `brew test`.

The initial Homebrew setup attempted to download Portable Ruby and API data and failed DNS resolution for `ghcr.io` and `formulae.brew.sh`; the copies above resolved those local tooling needs. The first audit attempted to download missing gems from `rubygems.org`; copying the existing audit bundle allowed the strict audit to run offline. A normal-account `brew cat node@24` read briefly enabled Homebrew developer mode; `/opt/homebrew/bin/brew developer off` restored its prior mode. No normal-account Gattini installation occurred.
